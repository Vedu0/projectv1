About Us

Smart RFID Inventory Management System

Our RFID Inventory Management System is designed to simplify and automate inventory tracking
using RFID technulogy and a real-time web dashboard.
The system helps users monitor containers, track product movement,
and manage inventory efficiently without manual checking.
Each container is integrated with RFID sensors
and LEDs to provide live status updates and visual indications.

What Our System Does

  • Real-time inventory monitoring
  • RFID-based product identification
  • Smart container tracking
  • Live dashboard updates
  • Product activity monitoring
  • Visual status indicators using LEDs
  • Automated data management

Features

Real-Time Dashboard

    The website displays live inventory data including:
  • Product ID
  • Container status
  • Entry and exit activity
  • Quantity updates
  • Timestamp tracking

Smart Containers

    Each RFID-enabled container can:
  • Detect tagged products
  • Show LED status indicators
  • Send data directly to the dashboard
  • Display individual activity logs

Interactive UI

    Our system includes:
  • Expandable inventory cards
  • Smooth animations
  • Dynamic data rendering
  • Modern responsive design

  • Node.js

  • Figma

Our Goal

The goal of this project is to create an efficient, low-cost,
and scalable inventory management solution that reduces manual work
and improves accuracy in warehouses, shops
and smart storage systems.
